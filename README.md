# RO RRF 即時狀態監控器 1.6.7

讀取本機台版 RO 的 RRF 錄影，顯示自身、目前隊伍的狀態，並監視自身寵物飽食度、提供聲音提醒。

## 1.6.7 更新

重新覆核未知狀態，補上 80 筆可讀名稱與 72 筆效果分類。名稱與效果分開確認；只有名稱能確認的項目繼續以「待確認」顯示，暫譯／暫稱保留標示。巧打列為減益，豐年頌列為增益，帶有持續代價的爆氣列為特殊。既有監控清單、卡片排列與提醒設定保留。

## 下載與使用

1. 前往 **[版本下載](https://github.com/jeremyd852-code/RO-RRF-Status-Monitor/releases/latest)**，下載 `RO-RRF-Status-Monitor-v1.6.7.zip`。
2. 完整解壓縮，雙擊 `RO-RRF即時狀態監控器.exe`。不需另外安裝 Python。
3. 在程式選擇 RRF 錄影來源，開始監控；自身與隊伍會從錄影資料自動辨識。

使用包內只有 EXE、`_internal`、`data` 及 `使用說明.txt`。兩個資料夾都是必要檔案，移動程式時請一起保留；請先解壓，勿直接在 ZIP 內執行。

程式適用 Windows 與台版 RO RRF；RO 樂園／Zero 不適用。只讀取錄影資料，不會操作遊戲或自動餵食。

## 功能

- 自身與目前隊伍的狀態監控、浮動狀態卡片、自訂規則及聲音提示。
- 狀態、消耗品分類與職業技能查找，以及內建資料維護。
- 自身寵物的飽食度與親密度顯示；寵物卡片是獨立浮動視窗，可單獨開關及調整外觀。
- 設定自動保存，並保留上一份備份；可從設定頁匯入舊設定。

## 寵物飽食提醒

新設定預設啟用聲音提醒，門檻為 25，可自行調整或關閉。只有收到新的有效飽食資料，且數值小於或等於設定門檻時，才會提醒：

| 飽食度 | 再次提醒最短間隔 |
|---|---|
| 大於 10，且仍在提醒門檻內 | 60 秒 |
| 0～10，且仍在提醒門檻內 | 20 秒 |

從大於 10 降入 0～10 時會立即提醒，仍受自訂門檻與開關控制；超過門檻即解除。沒有新數值時不會持續重播，歷史或失效資料也不補播。請持續提供更新中的 RRF 資料，才能取得新的飽食度。

隱藏寵物卡片或切換分頁不會關閉提醒；停止監控或切換錄影會清除舊資料。已有設定的門檻與關閉選擇會保留。音量為 0 時全部靜音；其他音量比例調整人聲，WAV 與系統提示音使用 Windows 音量。

## 選擇要監控的狀態

1. 在自訂規則選擇要設定的對象：自身或隊伍。兩份清單分開保存。
2. 要自己挑選時，使用「自訂監測」；「自動監測」會顯示實際讀到的狀態，不受自訂勾選清單限制。
3. 從「全部／搜尋」找名稱，也可直接看「目前身上」。職業技能、消耗品與異常狀態都是查找入口，同一範圍內勾選一次即可。
4. 「已勾選」可整理自己的清單。切入口或翻頁會保留勾選；本頁全選／取消只影響畫面這一頁。

職業只表示相關技能，不限制中了狀態的人。玩家或怪物造成的相同狀態用相同分類；同名但不同的狀態會保留編號辨識。已讀到但尚未對照名稱的效果會顯示「未確認狀態」，不會因為缺中文名稱而消失。

## 看懂卡片與提醒

狀態卡片每列依序顯示「狀態名稱、剩餘時間、效果分類」。名稱靠左，時間與最右側分類各自對齊；過長名稱以省略號顯示。

- 綠色：已確認增益生效。黃色／紅色：接近結束，預設為 30／15 秒，保留自訂門檻。
- 紫色「異常中」：已確認減益；即使快結束仍維持紫色。
- 藍灰「特殊」或灰色「待確認」：不把特殊或不明效果當成即將失去的增益。
- 「生效中／時間未提供」：沒有可靠倒數；「上次資料／建立中」：目前不是即時狀態。

一般狀態的逐項提醒預設關閉，可按需要開啟；勾選顯示不會自動開啟聲音。歷史重建與停更不發即時提醒，恢復時不補播舊提醒；同批到期合併為短提示。狀態卡片與寵物卡片分開，維持 RO 淡藍標題、白底與深字。

## 原始碼與建置

一般使用者下載 EXE 使用包即可。GitHub 的 Code／Download ZIP 以及 `RO-RRF-Status-Monitor-v1.6.7-source.zip`，供原始碼保存與開發使用。

原始碼執行需要 Python 3.10 以上及 Tk，可使用 `啟動監控器.vbs` 或 `啟動監控器.bat`。建置可使用 Python 3.13、PyInstaller，執行 `打包版本.ps1` 產生 EXE 使用包及獨立原始碼包；建置拒絕覆寫既有輸出。

執行 `python -B -m unittest discover -s tests` 可檢查監控範圍、設定與寵物提醒等行為；測試使用合成資料，不需個人 RRF。`python -B tests/test_scope_boundaries.py` 可單獨驗證自身與隊伍的資料範圍。

## 資料與隱私

個人設定、RRF 錄影、人物資料、快取與開發紀錄不隨附。首次執行會在程式資料夾建立 `config.json` 等設定與快取檔。

內建資料來源與授權文件狀態見 [DATA_SOURCES.md](DATA_SOURCES.md)。程式碼與遊戲資料的授權分別處理，本儲存庫未新增開源授權聲明。
